# Linh Nguyen — Beauty / Make-up Artist Portfolio

A static portfolio website for **Linh Nguyen, freelance make-up artist,
Adelaide SA**. Built 25 Nov 2026. No CMS, no database, no backend, no
environment variables, so it deploys on Vercel with zero config.

- Tech: Next.js 14 (App Router, TypeScript) + Tailwind CSS, `output: 'export'`
- Contact: nguyenlinhlinh9494@gmail.com (email only, no phone number known)
- Languages: English default, full Tiếng Việt toggle (EN/VI button in header)
- Sections (single page, anchor navigation): Hero, Portfolio gallery,
  Services, About, Experience, Contact / Enquire
- Enquiry form is mailto-only: it opens the visitor's email app addressed
  to Linh. Nothing is sent to or stored on any server.
- SEO: title/description/Open Graph in `src/app/layout.tsx`, plus
  `sitemap.xml` and `robots.txt` (generated by `src/app/sitemap.ts` /
  `src/app/robots.ts`). **The sitemap URL is a placeholder
  (`https://linh-nguyen.example.com/`); replace it with the real Vercel
  domain after deploying.**

## Audit findings

Before this site, Linh had **no portfolio website at all**. Her only
existing materials were a CV draft and two draft job applications for
beauty roles. This site was built from scratch, using the reference repo
below only for structure and ideas.

1. **No portfolio existed.** Nothing to audit or fix on a live site; this
   is a first portfolio, not a redesign.
2. **Reference repo:** `jyjy4work/Soobeen-choi-makeup-artist` (Next.js 14 +
   Tailwind, K-Beauty makeup artist; pages Home / Portfolio / Services /
   About / Contact; multilingual; Sanity CMS; `vercel.json`). Its page
   structure, gallery-with-filter, services list, language switcher and
   contact CTA were the model. **Its artist's content, photos and Sanity
   code were NOT copied.**
3. **Deliberate simplification vs the reference:** no Sanity CMS, no
   `next-intl`, no API routes, no ISR/revalidation. All content is local
   in `src/lib/content.ts`, so the site builds and deploys statically
   with no secrets, no Studio and nothing to keep in sync. (This also
   avoids the reference repo's known gaps: a brand-colour mismatch, a
   missing `/contact` revalidation path, and a hard-coded English
   "Career" label.)
4. **Borrowed ideas from other candidates:** a gallery-first layout with
   category filters, clear services with "Price on enquiry", and an
   email enquiry route (email only here, no phone/WhatsApp number was
   invented).
5. **Bilingual EN/VI is built in**, not an add-on: every section,
   service, portfolio label and form field is translated, because Linh's
   clients are mainly Asian and she works in Adelaide and Vietnam.
6. **Nothing invented:** no phone number, no prices (all services say
   "Price on enquiry"), no testimonials, no client names, no dates
   beyond "8 years" freelance makeup and "3 years" bar/gaming work,
   and no photos of real people or stock photos presented as Linh's work.
7. **What is still missing (needs Linh/David):** real portfolio photos
   (see below), a phone number if she wants one shown, prices if she
   wants them published, testimonials/client names, and confirmation
   of the CV (currently a draft) and of her earliest start date.
8. **Travel note is on the site:** available before or after travel
   5 Dec 2026 – 6 Jan 2027, and no driver's licence yet, so location /
   transport matters for bookings.

## How to add real portfolio photos

See `public/portfolio/README.md`. In short: save JPG/WebP files under
1 MB into `public/portfolio/` (e.g. `bridal-01.jpg`), add an `image`
field to the matching item in `src/lib/content.ts`, render it in
`src/app/page.tsx`, rebuild and redeploy. Only use photos Linh owns or
has permission to publish, with client consent where a real client is
shown. Until then the gallery shows clearly labelled gradient
placeholders, with a visible note: "Photos to add — replace these
placeholders with Linh's real work."

## Run locally / deploy

```bash
npm install
npm run build   # static export lands in ./out
npm run dev     # local preview at http://localhost:3000
```

Deploy: import this folder into Vercel (or push to GitHub first and
import the repo). No build settings to change, no environment variables.
The live URL is not set yet; after deploying, update the placeholder
domain in `src/app/sitemap.ts` and `src/app/robots.ts`.
